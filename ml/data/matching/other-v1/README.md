# Набор для рекомендаций категории «Другое»

Набор проверяет сценарий, в котором житель уже выбрал категорию «Другое», а ML показывает
до трёх похожих активных инцидентов того же дома и обязательный вариант «Создать новый».

## Состав

- `houses.jsonl` — 20 детерминированно выбранных домов из локальной выгрузки ГИС ЖКХ:
  по 10 в Брянске и Бахчисарае;
- `incidents.jsonl` — 60 активных синтетических инцидентов;
- `reports.jsonl` — 240 сообщений: зафиксированный seed и две LLM-переформулировки;
- `candidate_sets.jsonl` — 160 задач ранжирования, включая 40 случаев без правильного
  кандидата;
- `generation-plan.json` и `generations.jsonl` — воспроизводимость и происхождение;
- `manifest.json` — хэши, размеры, ограничения и стоимость генерации.

Дома, события, временные метки, split и правильные ответы формируются детерминированно.
AITUNNEL меняет только формулировку зафиксированного факта. В промпте используются короткие
референсы из Gold v2 только как пример стиля; адреса из них запрещено переносить.

Набор синтетический и не предназначен для загрузки как пользовательские обращения в рабочую
БД. Перед production-калибровкой требуется ручная проверка сложных отрицательных примеров.

## Воспроизведение

```powershell
uv run python -m src.ml.data.other_synthetic_cli `
  --houses-source <gis-zkh-json> `
  --output-dir ml/data/matching/other-v1 `
  --houses-per-city 10 `
  --env-file .env.local `
  --execute
```

Повторный запуск возобновляется по `generations.jsonl` и не отправляет уже выполненные задачи.

## Benchmark
